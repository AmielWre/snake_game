# 🐍 Snake Game

A classic Snake game that runs in your terminal, built with Python and curses.

## Install

**Windows only** (Mac/Linux: nothing needed):

```bash
pip install windows-curses
```

## Run

```bash
python game.py
```

## Controls

| Key | Action |
|-----|--------|
| Arrow keys or WASD | Move snake |
| Q | Quit |
| R | Restart after game over |

## About

Built for a Git workshop at the Hebrew University of Jerusalem — Bioinformatics Department.
Each feature of this game was added in a separate Git commit or branch to demonstrate version control concepts.
